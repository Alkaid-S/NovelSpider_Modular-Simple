# 简单~~且好用~~的小说爬虫器 

个人**用来学习**的小说爬虫程序。*当然，受到我喜欢读小说的原因。*

整体由`Python`编写，十分简洁！项目整体采用模块化设计，各代码分工明确（*~~好吧，能够有效地防止代码看起来头疼的问题~~*）

把本程序与其他大部分爬虫程序相比，你会发现本程序**并非**从目录页开始，而是像人阅读一般，从全书的**第一页**开始；<small>当然，速度远不及后者</small>

运行程序后你就可以发现只有**5行**可选设置，**5个**控制按钮以及**日志栏**和**预览栏**

### 可填设置栏：

- **起始网址**：输入你所要爬取小说**内容页**的第一页，形如：`https://www.example.com/XXXX/12345.html`
- **小说名称**：输入你爬取小说的名称。_如果你不知道，那就自己为小说取一个名字吧_
- **保存目录**：默认的保存目录是同目录下的`output\`文件夹，你也可以点击`浏览`来手动选择
- **启用等待**：在爬虫过程中进行区间内随机的等待，减小对网站的压力
- **最多章节**：输入最大章节数，当达到此数量时停止爬虫，不管小说是否完整爬取。
- **输出格式**：目前的可选项有`TXT`和`EPUB`，分别输出为`.txt`文件和`.epub`电子书

### 控制按钮栏：

- **开始爬取**：将以当前的配置开始爬虫
- **停止爬虫**：当爬虫进行时，此按钮可以停止爬虫，但停止不是即时的
- **测试网址**：对当前输入的网址进行测试，获取标题和正文（截取500字）
- **打开目录**：打开当前选择的`保存目录+小说名称`所在的文件夹
- **重置配置**：一键重置所有配置
- **进度预览**：显示当前进度

### 预览栏：

- **日志**：日志输出，占左侧
- **预览**：每章节的预览输出，占右侧
